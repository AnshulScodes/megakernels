# megakernels

Working copy of [Hyperstitioncc/Hyperkernel](https://github.com/Hyperstitioncc/Hyperkernel) (Hyperserve) for exploration and applied experiments.

Upstream ships fused megakernel runtimes for:

- **LLM** — DeepSeek-V4.1-Flash OpenAI-compatible server (4× NVIDIA B300)
- **Drive** — openpilot driving model
- **DNA** — Evo 2 7B sequence generation
- **World** — Matrix-Game 3.0 video generation

See [`Hyperkernel/README.md`](Hyperkernel/README.md) for build and CLI details.

Upstream: https://github.com/Hyperstitioncc/Hyperkernel
