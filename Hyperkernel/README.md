# Hyperserve

This repository contains the public implementations of the Megakernels generated by the Hyperkernel. This repository is in Alpha, and will be continuously updated over the next few weeks with more models and API simplifications, alongside performance improvements.

## Requirements

The current megakernels are compiled for NVIDIA B300s: 4 for LLMs, 1 for driving and DNA, 2 for world models. Each command runs on the first GPUs `CUDA_VISIBLE_DEVICES` lists. LLMs also need about 203 GB of host RAM for the Engram tables, mapped once for all 4 GPU processes.

The user must provide the model checkpoints as directories of `.safetensors` files; none is included in the repository. They are DeepSeek-V4.1-Flash with its `tokenizer.json`, openpilot v0.11.2's driving model, Evo 2 7B (`arcinstitute/evo2_7b`) and Matrix-Game 3.0 (`Skywork/Matrix-Game-3.0`).

Building needs Rust (see `rust-toolchain.toml`) and an NVIDIA driver R580 or newer:

```sh
cargo build --release
```

## CLI format

The top level CLI branches on the type of host server you want to run:

```sh
hyperserve <llm | drive | dna | world> --model <name> --weights DIR [options]
```

Each command picks its kernels from `kernels/b300/` and lists its options with `--help`.

## LLMs

```sh
hyperserve llm --model deepseek-v4.1-flash --weights DIR [--preset c1] [--host 127.0.0.1] [--port 8000] [--api-key KEY]
```

Runs an OpenAI-compatible server on 4 GPUs. `--weights` is the checkpoint directory of `deepseek-ai/DeepSeek-V4.1-Flash` at revision `314113f8a7dadb388215396ba5fbee2c610a04d6`, as published, which also holds the tokenizer. Requests are OpenAI chat or completion JSON; with `--api-key` (or `HYPERSERVE_API_KEY`) they must send `Authorization: Bearer KEY`.

There is one preset per maximum concurrency, all with a 1M-token context: `c1`, `c2`, `c4`, `c5`, `c6`, `c7` and `c8` (`c6` and `c7` run the `c5` kernels). Each preset's prefill plan is tuned in the binary.

## Driving

```sh
hyperserve drive --model openpilot --weights DIR --frames DIR [--count N] [--out DIR]
```

Runs openpilot's driving model over camera frames on 1 GPU and writes its outputs per frame. `--frames` holds `new_img.u8`: frames of 2 cameras by 6 planes of 128 by 256 bytes (the model's YUV 4:2:0 input), back to back. `--weights` is converted from openpilot v0.11.2's `driving_supercombo.onnx` (needs `onnx`, `numpy` and `safetensors`):

```sh
python scripts/openpilot_safetensors.py driving_supercombo.onnx DIR
```

## DNA

```sh
hyperserve dna --model evo2-7b --weights DIR --sequence FILE [--steps 1500] [--top-k K] [--seed S]
```

Generates DNA with Evo 2 7B on 1 GPU from a prompt sequence: a FASTA or plain file of A, C, G and T, its header lines skipped, the prompt and its steps within 1,048,576 positions. `--weights` is converted from `evo2_7b.pt` of `arcinstitute/evo2_7b` (needs `torch` and `safetensors`):

```sh
python scripts/evo2_safetensors.py evo2_7b.pt DIR
```

## World models

```sh
hyperserve world --model mg3 --weights DIR [--steps 4] [--actions FILE] [--frames-out FILE]
```

Generates video with MG3 on 2 GPUs: a first clip of 57 frames, then `--steps` chunks of 40. `--actions` is a text file of one line per frame, `w s a d pitch yaw`. Frames are written, as raw 1280 by 704 RGB, only with `--frames-out`; otherwise only timings print. `--weights` is the `base_distilled_model` directory of `Skywork/Matrix-Game-3.0`, with `MG-LightVAE_v2.pth`'s decoder converted into it (needs `torch` and `safetensors`):

```sh
python scripts/mg3_vae_safetensors.py MG-LightVAE_v2.pth DIR
```
